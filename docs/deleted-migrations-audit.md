- `keep / restore` was only expected for the ICO migrations that were deleted even though backend repository code still uses them. (These have been restored to `backend/migrations/postgres/`.)

Active code will continue to work because it gets the tables from the current PostgreSQL migrations.
- `review later` is a conservative label for any file where live code references a symbol, but an automatic replacement check was not obvious from this pass.
