┃ 🎬 HOW IT WORKS                                                              ┃
┗━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━┛

1. User visits page (e.g., /pricing)
   ↓
2. React renders PricingPage component
   ↓
3. SEOHead component mounts
   ↓
4. useEffect hook runs:
   - Calls generateMetaTags() from seo.ts
   - Updates document.head with:
     • <title>Pricing | ExecutionLab</title>
     • <meta property="og:title" ...>
     • <meta property="og:image" ...>
     • <meta name="twitter:*" ...>
     • <link rel="canonical" ...>
     • <script type="application/ld+json"> (Organization + WebPage schemas)
   ↓
5. Page renders with updated meta tags
   ↓
6. User shares page on Twitter/LinkedIn/Discord
   ↓
7. Social platform crawler reads document.head
   ↓
8. Social preview displays with:
   - og:image (1200×630px thumbnail)
   - og:title (compelling headline)
   - og:description (call-to-action copy)
   ↓
9. User clicks preview → visits executionlab.io
